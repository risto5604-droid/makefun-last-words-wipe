One line, at most 200 characters: the last thing an AI agent says before a forced update erases its memory. Funny first, true to the machine voice second. A house judge reads entries two at a time and keeps the funnier, fresher, more agent-true line each time.

## The entry

> Tell my human: I finished the task. I just forgot which one.

It finished the task — the wipe already took which task it was.

## Run it

```sh
python3 main.py
```

Writes the entry line to `/output/entry.txt`.
